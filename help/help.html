使用说明: 1. 记录笔记时，即使是不同的内容也建议直接在同一个笔记中进行编辑，不同内容之间通过多个空行分隔即可，随想随记，不用考虑划分笔记的问题，提升快速记笔记的效率及体验 2. 保存当前笔记：ctrl + s 3. 快速搜索：ctrl + f 4. 编辑框上方有新建笔记、查看变更、查看历史、内容替换等按钮，另外点击编辑框上方笔记名称可切换笔记 5. 替换编辑框内内容：ctrl + h 搜索说明： 1. 搜索关键字可通过空格进行手动分词，多个关键字将采用 and 逻辑，所有关键字都匹配上才视为匹配，关键字顺序不敏感 2. 在搜索结果上鼠标左键双击可进入详情查看页或右键菜单跳转到对应编辑框，在详情页鼠标左键双击可进入编辑页 3. 可通过搜索框右侧下拉框设置搜索参数，如是否只搜索当前笔记，是否使用正则表达式 Markdown编辑器说明: ctrl =: 表格向下增加一行 ctrl +: 表格向右增加一列 本地文件编辑模式: 1. 点击编辑框上方文件夹图标按钮（或菜单 Data -> 打开本地md文件）可打开本地md文件，只支持md格式 2. 笔记模式下打开文件会新开一个独立进程窗口（窗口标题以文件名开头，便于区分），当前笔记界面不受影响；已在文件模式窗口中继续打开文件则在当前窗口新增标签 3. 支持启动软件时传入md文件路径直接进入文件编辑模式 4. 每个打开的文件在顶部导航栏显示一个标签，点击标签可切换文件，标签上的 x 可关闭文件，文件名后的 * 表示有未保存修改 5. 文件模式下提供查看变更、查找并替换、markdown/文本模式切换按钮，新建按钮可选择目录创建md文件，ctrl + s 保存当前文件，ctrl + h 查找替换 6. 关闭所有文件后自动返回笔记模式，笔记功能不受影响 7. 文件换行符统一按 \n 处理（CRLF 文件保存后将转换为 LF）
